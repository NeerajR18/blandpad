# blandpad
Submission for Hack Club Blueprint 2026

blandpad is a basic 3x3 macropad with the XIAO RP2040 and KMK firmware.
It has buttons for media control, basic shortcuts and for opening applications.
The project was made to start learning about CAD and PCB Design.

# Features
- 3x3 Matrix layout with mechanical keys
- 3D printed case

# CAD
The case was designed in Autodesk Fusion
